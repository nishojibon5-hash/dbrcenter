# DBR Car Workshop - Netlify Deployment Guide (নেটলিফাই ডিপ্লয় নির্দেশিকা)

আপনার **DBR Car Workshop** প্রজেক্টটি Netlify-তে ডিপ্লয় করার জন্য সম্পূর্ণ তৈরি করা হয়েছে। ফাইলগুলো `dist/` ফোল্ডারে অপ্টিমাইজড অবস্থায় প্রস্তুত রাখা আছে।

---

## 🚀 পদ্ধতি ১: ড্র্যাগ অ্যান্ড ড্রপ (Drag & Drop) পদ্ধতি (সবচেয়ে সহজ - ১ মিনিট)

১. AI Studio-এর উপরের ডানপাশের সেটিংস মেনু থেকে প্রজেক্টটি **Export ZIP** বা ডাউনলোড করুন।
২. আপনার কম্পিউটারে ফাইলটি আনজিপ করুন।
৩. ব্রাউজারে [app.netlify.com](https://app.netlify.com) এ লগইন করুন।
৪. Netlify ড্যাশবোর্ডে **"Sites"** ট্যাবে যান।
৫. নিচে **"Want to deploy a new site without connecting to Git? Drag and drop your site output folder here"** বক্সে আপনার প্রজেক্টের **`dist`** ফোল্ডারটি ড্র্যাগ অ্যান্ড ড্রপ (টেনে এনে ছেড়ে দিন) করুন।
৬. ৫ সেকেন্ডের মধ্যে আপনার সাইট লাইভ হয়ে যাবে এবং আপনি একটি লাইভ URL (যেমন: `your-site.netlify.app`) পেয়ে যাবেন!

---

## 🚀 ১ মিনিটে Netlify সমস্যা সমাধানের উপায়:

### সমস্যাটি কেন হয়েছিল?
GitHub থেকে Netlify-তে প্রজেক্ট কানেক্ট করার সময় Netlify ডিফল্টভাবে রুট ডিরেক্টরিতে `index.html` খোঁজে অথবা আপনি যদি **Publish directory** ফিল্ডে কিছু না দিয়ে থাকেন, তাহলে Netlify রুট থেকে ফাইল পাবলিশ করে। পূর্বে ফাইলটি কেবল `dist/` ফোল্ডারে ছিল এবং উপরে একটি প্রিভিউ বার ছিল।

### আমরা যা সমাধান করেছি (অলরেডি ফিক্সড):
1. **ডুয়াল ডিপ্লয় সাপোর্ট:** এখন প্রজেক্টের রুটে (`index.html`) এবং `dist/` ফোল্ডারে (`dist/index.html`) উভয় স্থানেই পূর্ণাঙ্গ ওয়েবসাইট রাখা হয়েছে। আপনি Netlify-তে Publish directory হিসেবে `dist` দিন বা খালি রাখুন—সব অবস্থাতেই সাইট নিখুঁতভাবে চলবে!
2. **প্রিভিউ বার রিমুভ:** উপরের অতিরিক্ত মোড ও ফেক ব্রাউজার বার মুছে দিয়ে সাইটটিকে ১০০% ন্যাচারাল ফুল-স্ক্রিন রেসপন্সিভ করা হয়েছে।
3. **Netlify সেটিংস:**
   - **Build command:** খালি রাখুন অথবা `mkdir -p dist && cp index.html dist/index.html`
   - **Publish directory:** `dist` অথবা `.` (যেকোনোটি দিলেই লাইভ হবে)
4. **স্বয়ংক্রিয় রি-ডিপ্লয়:** গিটহাবে পুশ করলেই Netlify স্বয়ংক্রিয়ভাবে ২ সেকেন্ডে বিল্ড সম্পন্ন করে সাইট লাইভ করে দেবে।
