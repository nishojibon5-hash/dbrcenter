# DBR Car Workshop - Vercel Deployment Guide (ভার্সেল ডিপ্লয় নির্দেশিকা)

আপনার **DBR Car Workshop** প্রজেক্টটি Vercel-এ ডিপ্লয় করার জন্য শতভাগ প্রস্তুত করা হয়েছে। `vercel.json` কনফিগারেশন, SEO ফাইল (`robots.txt`, `sitemap.xml`), বাংলা ফন্ট এবং সমস্ত ইমেজ অ্যাসেট সঠিকভাবে সাজানো রয়েছে।

---

## 🚀 পদ্ধতি ১: GitHub থেকে Vercel-এ ১ ক্লিকে ডিপ্লয় (সবচেয়ে সুবিধাজনক ও রিকমেন্ডেড)

যেহেতু আপনার গিটহাব রিপোজিটরিতে (`nishojibon5-hash/dbrcenter`) কোড ইতোমধ্যে কানেক্টেড আছে:

১. ব্রাউজারে যান: **[vercel.com](https://vercel.com)** (লগইন না থাকলে GitHub দিয়ে লগইন করুন)।
২. ড্যাশবোর্ডে **"Add New..."** বাটনে ক্লিক করে **"Project"** নির্বাচন করুন।
3. **"Import Git Repository"** লিস্ট থেকে **`nishojibon5-hash/dbrcenter`** খুঁজুন এবং পাশে থাকা **"Import"** বাটনে ক্লিক করুন।
৪. **Configure Project** স্ক্রিন আসবে:
   - **Project Name:** `dbrcenter` (বা আপনার পছন্দের নাম)
   - **Framework Preset:** `Other` (স্বয়ংক্রিয়ভাবে থাকবে)
   - **Root Directory:** `./` (ডিফল্ট যা আছে তাই থাকবে)
   - **Build and Output Settings:** কোনো কিছু পরিবর্তন করার প্রয়োজন নেই (আমরা `vercel.json` দিয়ে সবকিছু রেডি করে দিয়েছি)।
৫. এবার নীল রঙের **"Deploy"** বাটনে ক্লিক করুন!
৬. মাত্র **১০ থেকে ২০ সেকেন্ডের** মধ্যে আপনার ওয়েবসাইট লাইভ হয়ে যাবে এবং Vercel আপনাকে একটি ফ্রি ডোমেইন লিঙ্ক দেবে (যেমন: `dbrcenter.vercel.app` বা অনুরূপ)।

---

## 🚀 পদ্ধতি ২: Vercel CLI দিয়ে সরাসরি টার্মিনাল থেকে ডিপ্লয় (ঐচ্ছিক)

আপনি যদি আপনার নিজস্ব কম্পিউটারের টার্মিনাল থেকে ডিপ্লয় করতে চান:
```bash
npm i -g vercel
vercel
```
এরপর Vercel-এর প্রম্পটে শুধু Enter চাপলেই সরাসরি লাইভ হয়ে যাবে।

---

## 🛠️ Vercel-এর জন্য আমরা যা যা রেডি করেছি:

1. **`vercel.json` কনফিগারেশন:**
   - ফাস্ট লোডিং ও ক্লিন URL হ্যান্ডলিং।
   - বাংলা ফন্ট (`Li-Chutro-Bold.ttf`) যাতে CORS বা অন্য কোনো ব্লকিং ছাড়া নিরাপদে লোড হয় তার জন্য স্পেশাল হেডার্স।
   - ইমেজ ও স্ট্যাটিক অ্যাসেটের জন্য ১ বছরের ব্রাউজার ক্যাশিং (সুপার ফাস্ট পারফরম্যান্স)।
   - সাইটের সিকিউরিটি নিশ্চিত করতে `X-Frame-Options`, `X-Content-Type-Options` ইত্যাদি সিকিউরিটি হেডার্স।
2. **ডুয়াল ফোল্ডার সাপোর্ট:**
   - রুট ডিরেক্টরি (`.`) এবং `dist/` উভয় ফোল্ডারেই সকল ফাইল ও ছবি প্রস্তুত।
3. **সার্চ ইঞ্জিন অপ্টিমাইজেশন (SEO):**
   - `robots.txt` এবং `sitemap.xml` স্বয়ংক্রিয়ভাবে যুক্ত।
4. **স্বয়ংক্রিয় আপডেট (Continuous Deployment):**
   - পরবর্তীতে গিটহাবে নতুন কোনো কোড পুশ করলেই Vercel নিজে থেকেই নতুন ভার্সন লাইভ করে দেবে।

---

## 🌐 কাস্টম ডোমেইন যুক্ত করার নিয়ম (যেমন: `dbrcarworkshop.com`):
1. Vercel ড্যাশবোর্ডে প্রজেক্টে গিয়ে **Settings > Domains** এ যান।
2. আপনার ডোমেইন নামটি লিখুন এবং **Add** ক্লিক করুন।
3. Vercel প্রদত্ত DNS রেকর্ড (A Record বা CNAME) আপনার ডোমেইন প্রোভাইডারে সেট করুন। Vercel স্বয়ংক্রিয়ভাবে বিনামূল্যে SSL সার্টিফিকেট (HTTPS) সক্রিয় করে দেবে।
